### Why ap-south-2

`maxAgents` is **0 in us-east-1, us-west-2, eu-west-1 and ap-south-1**, and at
the full default of 1,000 in ap-south-2. The quota is per-region. Four zeroed
regions were nearly generalised to "all of them", which would have left us
waiting on a support ticket that did not need to exist.

Side effect worth keeping: Hyderabad is in India, so the table and the runtime
are both in-country. The model calls are not, and never were.

### P1 — real gaps, visible to a judge who asks

**1. There is no authentication.** Anyone who can invoke the endpoint can read
any case by id and approve any filing by passing any `member_id` string. Hard
rule 4's "the liability lands on a named person" is currently only as strong as
the caller's honesty. **The frontend team must know this**: a UI that lets
someone type their own `member_id` makes the signature meaningless.

**2. A cloud runtime cannot reach `localhost` institution desks.**
`institutions/server.py` runs on ports 9001–9005 on someone's laptop. The
deployed agent cannot call them. Either demo the end-to-end filing locally, or
give the desks public endpoints and set `WARD_ENDPOINT` and friends at deploy.
**Decide before recording, not during.**

**3. Bedrock models are still blocked account-wide** —
`ValidationException: Operation not allowed`, re-probed today in us-east-1 and
us-west-2. Support case 178898467100367. The spine runs anyway because its
nodes take an injected model and fall back to deterministic parsing, measured
at `totalTokens: 0`. It costs quality, not availability.

**4. The trace UI does not exist.** `demo/trace_ui/` is an empty untracked
folder. The data is all there — spans carry `case_id`, and AgentCore
instruments the runtime — but nothing renders it.

### P2 — smaller, known, unowned

**5. `list_cases` shows only open cases.** `open_cases()` excludes RESOLVED,
WITHDRAWN and DORMANT, so "your complaint was resolved" — the most satisfying
screen in the product — cannot be built. Needs a by-household query on
`core/store.py`.

**6. Still open from earlier reviews, none regressed:** `compose_filing()`
needs an `rr_number` nothing collects (25 of 31 curated entries); no household
registry, so `segment` must arrive in the payload; no version guard on `Case`
with three writers; no backfill for `FILING#` pointer rows; `.env.example` is
stale and lists `MODEL_SMALL`, `MODEL_MID`, `MODEL_LARGE` and `TAU`, which
nothing reads.
