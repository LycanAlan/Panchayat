## 3. Contract changes — read this part

These change how your code has to behave. Nothing else here does.

### `segment` is now REQUIRED in the request payload

```python
{"household_id": ..., "member_id": ..., "text": ..., "language": ...,
 "segment": "ward12-4thcross"}      # <- required
```

The merged endpoint answered `completed`, returned a `case_id`, and **filed
nothing**. Found by POSTing a real report at `app.py` while 279 tests were
green.

The happy path only ever worked because the Warden was stubbed, and the stub
defaulted the segment to a fixture value. The real `minimise()` correctly emits
none — `HouseholdPosition` is frozen and carries no segment.

Missing it now returns `unrouted_reason: "no_segment"` and **refuses before the
graph runs.** It used to persist an unroutable claim with `segment=""`, and
under DynamoDB every one of those lands in the same GSI1 partition.

**There is no household registry to look a segment up from.** Nothing in the
repo writes a Household row. Building one is a new entity plus store work —
**raised, not invented.** See §5.

### `RealClock.schedule()` now raises `SchedulerNotConfigured`

When `WATCHDOG_LAMBDA_ARN` / `SCHEDULER_ROLE_ARN` are unset it raises **before
touching boto3**, instead of calling EventBridge with an empty ARN. Catch that
specific type if you schedule. Do not catch broadly, or you will hide a real
scheduler outage.

It exists because scheduling from the request path put a live AWS call in the
offline suite — 36 seconds of botocore retries, against the promise that
everything runs on `PANCHAYAT_BACKEND=memory` with no credentials.

### `core/db.py` gained optional functions your backend needs

**Kartik — `core/store.py` needs DynamoDB implementations of:**

```
sign_filing()   unsigned_filings()   get_filing()     # hard rule 4
stalled_cases()                                       # the digest's queue
```

They sit in `db.OPTIONAL`, so your backend still imports and the seam raises by
name instead of binding `None`. **Until they land, hard rule 4 works on the
memory backend and nowhere else** — the deployed path cannot record a
signature, and Alakshendra's `file()` correctly refuses everything.
